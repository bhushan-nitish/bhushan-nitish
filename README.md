## What I work on

- **Production AI agents**: stateful runtimes, context, next-best actions and safe execution, built on GPT (Azure OpenAI) and Claude models, chosen per task on cost, accuracy and latency
- **Systems of record to systems of execution**: agents over CRM, ERP, ticketing, commerce and messaging data, in any vertical; integrations with Salesforce, Zoho CRM, Freshsales, ERPNext, Shopify and WhatsApp Business
- **Agent reliability**: deterministic validation, replay/evaluation, observability and incident analysis
- **Human-in-the-loop systems**: staff handoff, approval boundaries and outcome evidence
- **Backend & platform architecture**: multi-tenant systems, events, APIs and integrations

## How I build: with Claude and GPT, openly

I own the design and the decisions. Claude Code is my pairing partner for code, tests and incident analysis; GPT is a second reviewer on plans and designs.

- **Multi-agent build and review**: a small engineering team working alongside coordinated AI coding and review agents with typed handoffs
- **Critics before shipping**: changes are reviewed by an agent that did not write them and is told to find the flaw
- **Evidence before claims**: "it works" means a test run or a production record, not a reading of the code

Work done with Claude carries its co-author credit.
